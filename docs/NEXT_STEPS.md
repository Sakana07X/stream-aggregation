# 后续开发计划

## 当前状态

当前版本已经能够通过 Release 构建和自动化测试，但暂不作为可交付测试发行包。原因是远程 OneBot 和模型端点仍允许明文传输，密钥临时文件的 Git 忽略规则也需要补齐。

## 阶段一：安全修复

1. 非回环 OneBot 连接强制使用 WSS。
2. 非回环模型端点强制使用 HTTPS。
3. 保留本机回环地址的 WS/HTTP 能力，并在设置界面明确标注其仅限本机。
4. 忽略 `secrets.dat.tmp`、`secrets.dat.corrupt` 等密钥派生文件。
5. 为协议限制和文件保护补充测试。

## 阶段二：发行包验证

1. 运行全部测试、Release 构建和依赖漏洞扫描。
2. 生成 `win-x64` 自包含初步发行目录。
3. 在没有真实消息写入风险的条件下启动客户端。
4. 连接本机 SnowLuma，验证消息接收、群白名单、SQLite 保存、摘要页面和待办页面。
5. 验证模型不可用时的本地回退。
6. 验证托盘、暂停/恢复和紧急通知。

## 阶段三：测试反馈

- 记录启动环境、SnowLuma 连接结果、摘要准确性和待办结果。
- 修复阻断性问题后重新发布测试包。
- 根据测试结果再决定是否加入安装包、图片文件解析和手机网页。

## 发行验收标准

- 远程连接不会通过明文传输 token、API Key 或群消息。
- 测试和 Release 构建全部通过。
- 测试包不会包含真实数据库、日志、token 或 API Key。
- 客户端可以连接本机 SnowLuma 并展示摘要和待办。
- 模型失败不会导致消息接收停止。
