## 已知限制

- `ISummarizationClient` 目前只返回 `Digest`，不返回 `ActionItem`，待办页暂无实际数据。
- OneBot 事件解析存在两套实现（客户端内嵌映射器与独立解析器），功能重叠待合并。
- 设置页校验缺少可视化提示，本机回环范围说明只以错误文案形式呈现。

## 发行验收标准

- 远程连接不会通过明文传输 token、API Key 或群消息。
- 测试和 Release 构建全部通过。
- 测试包不会包含真实数据库、日志、token 或 API Key。
- 客户端可以连接本机 SnowLuma 并展示摘要和待办。
- 模型失败不会导致消息接收停止。
