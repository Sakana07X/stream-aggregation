# 后续开发计划

## 当前状态

当前代码已完成安全传输限制、密钥文件保护、OneBot 解析合并和行动项端到端链路。Release 构建和自动化测试通过，但以下发行阻断问题仍需修复：OneBot 认证失败时禁止匿名连接；行动项状态不能被后台保存覆盖；行动项部分保存失败不能标记批次完成。

## 阶段一：发行前修复

1. 认证失败时禁止 OneBot 匿名连接。
2. 修复行动项状态并发覆盖。
3. 修复行动项部分保存失败后的批次状态和重试。
4. 增加行动项链路、失败恢复和旧数据库迁移测试。

## 阶段二：发行包验证

1. 从干净环境运行全部测试、Release 构建和依赖漏洞扫描。
2. 生成 `win-x64` 自包含发行目录。
3. 检查发行目录不包含真实数据库、日志、token、API Key 或 SnowLuma 运行数据。
4. 连接本机 SnowLuma，验证消息接收、群白名单、SQLite 保存、摘要页面和待办页面。
5. 验证模型不可用时的本地回退、托盘、暂停/恢复和紧急通知。

## 阶段三：测试反馈

- 记录启动环境、SnowLuma 连接结果、摘要准确性和待办结果。
- 修复阻断性问题后重新发布测试包。
- 根据测试结果再决定是否加入安装包、图片文件解析和手机网页。

## 已知限制

摘要页按版面分为紧急、待办、学习、普通四组，`DigestCategory.Notice` 本版不单独展示。设置页的回环范围提示和部分 WinUI 页面行为仍需要手动验收。
