# 后续开发计划

## 当前状态

远程明文传输限制、密钥文件 Git 保护、OneBot 解析合并和行动项端到端链路均已完成。
Release 构建 0 警告 0 错误，284 项测试全部通过，无漏洞依赖。三个数据页面已接入真实存储。

## 阶段二：发行包验证

1. 生成 `win-x64` 自包含初步发行目录。
2. 在没有真实消息写入风险的条件下启动客户端。
3. 连接本机 SnowLuma，验证消息接收、群白名单、SQLite 保存、摘要页面和待办页面。
4. 验证模型不可用时的本地回退。
5. 验证托盘、暂停/恢复和紧急通知。

## 阶段三：测试反馈

- 记录启动环境、SnowLuma 连接结果、摘要准确性和待办结果。
- 修复阻断性问题后重新发布测试包。
- 根据测试结果再决定是否加入安装包、图片文件解析和手机网页。

## 已知限制

- 摘要页按版面分为紧急、待办、学习、普通四组，`DigestCategory.Notice` 本版不单独展示。
- 设置页校验缺少可视化提示，本机回环范围说明只以错误文案形式呈现。
- 回退摘要的批次记为 Completed 并附警告日志，诊断信息只在应用日志中，不落 `llm_calls` 表。
- App 层页面逻辑没有单元测试（WinUI 程序集无法在测试宿主加载），仅有源码断言测试和阶段二手动验证。

## 发行验收标准

- 远程连接不会通过明文传输 token、API Key 或群消息。
- 测试和 Release 构建全部通过。
- 测试包不会包含真实数据库、日志、token 或 API Key。
- 客户端可以连接本机 SnowLuma 并展示摘要和待办。
- 模型失败不会导致消息接收停止。
